# Best Homz — Supabase

## Apply migrations

Link your project and run migrations with the [Supabase CLI](https://supabase.com/docs/guides/cli):

```bash
supabase login
supabase link --project-ref <your-project-ref>
supabase db push
```

Or run each file in order via the Supabase Dashboard **SQL Editor**:

1. `migrations/001_initial_schema.sql`
2. `migrations/002_indexes.sql`
3. `migrations/003_rls.sql`
4. `migrations/004_storage.sql`
5. `migrations/005_seed_categories.sql`
6. `migrations/007_seed_rooms_collections.sql` (if using rooms/collections)
7. `migrations/008_phase7_notes_and_cart_unique.sql`
8. `migrations/009_phase8_guest_quote_claim.sql`

## Environment

Copy `.env.example` to `.env.local` and set keys from **Project Settings → API**.

## Phase 5 product import

After reconciling the live gallery (`npm run catalog:reconcile`):

1. `npm run catalog:validate`
2. Configure `.env.local` (see `.env.example`)
3. `npm run catalog:import` — upserts `data/products-import.json` by product `slug`

## Notes

- **Quote numbers** are generated by trigger (`BH-Q-YYYY-######`).
- **Pricing** lives in `product_pricing`; customer UI uses `config/pricing.js` (`SHOW_PRICES`).
- **Guest carts** use server actions + `SUPABASE_SERVICE_ROLE_KEY` and httpOnly `bh_cart_session` cookie (see `docs/phase7.md`).
- First **admin** user: sign up, then set `profiles.role = 'admin'` in SQL for that `auth.users` id.
